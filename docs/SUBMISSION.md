## Short description

A voice-first fictional cinema: tell the box office your mood and time, compare films on screen, and turn the conversation into a carefully checked demo booking. Built with AssemblyAI.

## Review boundaries

All film content and bookings are fictional. The model proposes operations, server code validates them, and the visitor explicitly confirms. No payments, actual reservations or real-film data are claimed. Typed conversation controls were withheld after inconsistent live follow-ups.
